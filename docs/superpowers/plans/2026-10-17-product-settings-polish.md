# AI Underlay 产品化改造

日期：2026-10-17。基线：`db27b5e`。分支：`codex/product-settings-polish`。

用户已授权无需提问、自主选择合理方案并实施；本轮不提交、合并、推送或发布。

## 问题与选择

1. 六个等权标签缺少任务层次，外观页混合布局、活动、调试样例及技术说明；固定窗口难以阅读长表单。采用可调整大小的原生侧栏，常用与高级设置分组，统一标题、说明、即时保存反馈。保留现有数据契约，不重写渲染器。
2. 布局依赖未充分表达，关闭活动/减少动态效果后仍可调整无效参数；原始 fixture key 不适合普通用户。明确依赖，禁用并解释无效选项，预览必须明显标识并可退出。
3. 主题个人覆盖优先于主题，但缺乏可见提示；颜色和材质控件的默认值不一定来自当前主题。显示有效值及覆盖状态，提供明确且局部的恢复操作，高级材质和文件工具折叠。
4. 连接界面使用开发术语；重新检测、代理保存和 Hook 安装可能吞错或提前报告成功。用可执行状态、加载中反馈、错误反馈和合理输入校验代替假成功；移除未实现安装器的产品入口。
5. 设置保存失败静默；弹窗未明显区分预览、禁用和过期状态。暴露持久化错误，补充可操作空状态和数据新鲜度标识。

只调整文案无法解决状态问题；全量重写数据与渲染架构风险高且无助本轮目标。因此选择界面组织加针对性状态修复。

## 执行分工

- 子任务 A：设置侧栏、窗口、布局与动效页、预览入口。负责 SettingsRootView、SettingsWindowController、AppearanceTab 及相关新 UI 文件。
- 子任务 B：主题设置的有效值、覆盖状态、恢复操作、渐进展开。仅负责 ThemeTab 及其直接相关测试。
- 子任务 C：服务商、引擎和 Hook 配置流程。负责 ProvidersTab、EngineTab、AgentTab 及必要的纯辅助类型和测试。
- 主任务：持久化可靠性、菜单栏弹窗、诊断、审查集成、文档和验收。

所有子任务使用 `group/auto-deepseek-v4-1-flash`，推理等级 `max`。直接编辑当前工作区，写入范围互斥，不操作 Git 分支或提交。

## 验收

- 使用中文产品文案和 macOS 原生控件；基本操作无需理解 CLI、fixture、provider 等内部名词。
- 禁用、预览、连接失败与保存失败均可区分；不可伪造额度、登录成功或真实吞吐速度。
- 主题不改额度长度或告警优先级，保留双侧拆分配色、即时设置、Reduce Motion、点击穿透及已有渲染效果。
- 执行 `xcodegen generate`、完整项目测试、`Scripts/check-domain-purity.sh`、Debug 构建和 `git diff --check`；增加有意义的状态逻辑回归测试。
- 尽可能打开构建版本检查实际设置窗口并保留截图；离线渲染、自动测试与真实窗口验证分别记录。
- 交付问题清单、已实施修改、验证结果、剩余限制及本地应用路径。
