## What was wrong

Two separate complaints, fixed separately:

1. **Too slow.** The default floor was `0.34 Hz` — 2.9 s per cycle. Speed is
   normally unmeasured, so the floor alone decides the tempo on screen; a first
   glance could not tell Running from idle.
2. **Motion not visible enough.** The ray *texture* was static. Only three
   copies of it were scaled vertically in `0.94…1.00` (≤2 pt on a 30 pt bar),
   so turning 横穿扫光 off left a nearly still picture, and even with it on the
   eye tracked a moving mask rather than the rays themselves.

## What changed

| Area | Before | After |
|---|---|---|
| Default tempo | `0.34 Hz` (2.9 s) | `0.70 Hz` (1.4 s), ceiling `1.10 Hz` |
| Presets | 2.9 / 2.0 / 1.4 / 1.1 s | 2.0 / 1.4 / 1.1 / 0.9 s, one click each |
| Ray motion | static texture + `scale.y` 0.94–1.0 | per-ray height/alpha as a function of time |
| Animated layers | 3 beds + 3 peaks + 3 masks + 2 fields | 1 curtain (+ attention/ambient) |
| Frame cadence | continuous transforms | 16–24 frames/cycle (11–17 fps), discrete CA keyframes |
| Wave strength | none | `waveIntensity` 0.30–1.00 (default 0.75), visual only |
| Travelling light off | crest parked, rays almost still | crest parked, **wave still propagates** |

`SpectrumWaveModel` is the single source of truth: two travelling sine waves
with per-ray phase offsets (`0.072`, `0.27` rad) plus a local crest kernel
(`sigma = 0.28 × lane × 0.56`), the same construction as the V5 lab's
`repaint()`. `SpectrumFrameRasteriser` bakes each phase into one bitmap;
`SpectrumFrameCache` keeps an LRU bounded at 16 MiB; the layer plays the
sequence with one discrete `contents` keyframe animation.

## Offline phase matrix

`parked-…` (traveller off), four phases each, generated by
`TEST_RUNNER_GLASS_PREVIEW_DUMP=1`.

Measured from those PNGs (48 pt tall, 640 px wide, 2x): the topmost ray ink
varies by 15–20 px across the lane at a single phase, and rays at the same
x change height between phases — with the traveller off as well. That is the
per-ray wave, not a uniform scale.
