设计观察

A · Aurora Glass 更偏精致的彩色玻璃光幕，色彩在内部连续变化，适合希望有品牌识别度又保留通透感的风格。B · Acrylic Glow 更偏系统级深色磨砂，颜色更克制，依赖微小颗粒与边缘高光营造触感。你可以把两者调到相同参数，直观看出渲染材质而非单纯颜色的差异。

此 Demo 使用浏览器 backdrop-filter、CSS 和低帧率 Canvas 光线模拟设计方向；并非原生 NSVisualEffectView 的实测效果，也不包含真实 AI 会话数据。导出的实验参数尚不能直接导入当前 AIUnderlay Theme Engine，后续需扩展 JSON Schema。AIUNDERLAY / GLASS STUDY 05
