# Glass Spectrum preview PNGs

Generated by `GlassPreviewTests` (not hand-drawn, not the browser demo):

```bash
TEST_RUNNER_GLASS_PREVIEW_DUMP=1 Scripts/test.sh \
  -only-testing:AIUnderlayKitTests/GlassPreviewTests/test_dumpPreviewPNGsWhenRequested
```

Each file is one provider lane rasterised at the real menu-bar height (30 pt,
2x scale) through `GlassQuotaRenderer` + `GlassSpectrumRenderer` +
`AttentionLightRenderer`, with the selected V5 numbers.

`AgentSignals.unreadCount` at 0 until the durable completion ledger merges
(branch `codex/unread-completion-attention-ribbon`); these lanes exist so the
green light can be reviewed before then.
